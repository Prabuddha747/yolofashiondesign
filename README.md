# yolofashiondesign

A Computer Vision engineering project (YOLO is one module inside it, not the
whole thing) built on the Kaggle dataset
[`lahbibfedi/fashion-dataset-with-annotation`](https://www.kaggle.com/datasets/lahbibfedi/fashion-dataset-with-annotation).

Garment detection (YOLOv8) → explainable inference pipeline → visual
similarity recommendation → real-time camera demo → analytics dashboard.

  the current implementation step, in order, with expected results at each
  step.
- **Architecture & verified dataset facts:** [docs/00_Project_Architecture.md](docs/00_Project_Architecture.md)
- **Per-module documentation:** [docs/](docs/) (`01_Dataset_Analysis.md`, ...,
  one file per pipeline stage)
